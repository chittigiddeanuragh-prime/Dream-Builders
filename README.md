# Dream-Builders — CampusMind AI Platform

CampusMind AI is an all-in-one college co-pilot web application built for students. It features OpenRouter LLM agent reasoning with live tool execution, a full-stack Flask REST API, Tailwind CSS dark neon aesthetic, and 10 real-world integrations.

---

## 🌟 Key Features

1. 🎓 **AI Study Coach / Chat**: Context-aware tool execution loop powered by OpenRouter (`openai/gpt-4o-mini`).
2. 💼 **Assignments & Deadlines**: Countdown timers (2d, 4d, 8d, 10d, 13d), subtask checklists, and assignment modal.
3. 🔌 **10 Real-World Integrations**: Google Calendar, Microsoft Teams, Slack, College ERP, Notion, Gmail, Google Drive, GitHub, YouTube Learning, LinkedIn.
4. 📚 **Notes to Knowledge Base**: Pre-populated course notes, PDF parser, "Open Note" content viewer, and "+ Add Note" creator.
5. 🗺️ **Campus Map Navigator**: 15 campus locations with step-by-step turn-by-turn navigation modal.
6. 🎓 **Scholarships & Opportunities**: National scholarships, Google internships, Unstop hackathons with skill match % & gap analysis.
7. 🧪 **Lab Exams & Viva Solver**: Viva questions generator, past paper topics & solutions.
8. 🎯 **Career Roadmaps**: Step-by-step learning paths for AI/ML Engineer and Full-Stack Developer.

---

## 🛠️ Tech Stack

- **Frontend**: Single Page Application (HTML5, Tailwind CSS, FontAwesome 6, JavaScript ES6+)
- **Backend**: Python Flask REST API
- **AI Agent**: OpenRouter API with multi-step tool calling dispatcher

---

## 🚀 Running Locally

```bash
cd backend
python app.py
```
Open `http://127.0.0.1:5000` in your web browser.
